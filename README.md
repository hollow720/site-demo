# Mom's Recipe Book

My mom's recipe book, turned into a website. It puts my family's recipes in one place so they're easy to find and don't get lost.
## Why I Made It

Our recipes were in a physical book. That makes them hard to search, hard to share, and easy to lose if the pages get damaged. I wanted all of them saved online.

## What It Has

- A home page that lists all 25 recipes, and each one links to its own page
- A page for every recipe with the ingredients, the steps, and a photo
- Sections for recipes with more than one part, like dough and stuffing

## Built With

- HTML
- CSS (one stylesheet for the whole site, with Flexbox for the layout)

No JavaScript or frameworks. Just plain HTML pages.

## How to Run It

It's a static site, so there's nothing to install.

1. Clone the repo:

   ```bash
   git clone https://github.com/hollow720/recipe_book.git
   cd recipe_book
   ```

2. Open `index.html` in your browser.

## Files

```
recipe_book/
├── index.html           # home page with the list of recipes
├── 1.html ... 25.html   # one page per recipe
├── css/
│   └── style.css        # styles for every page
└── img/                 # recipe photos and page decorations
```
